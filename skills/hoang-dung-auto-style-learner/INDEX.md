# Bản đồ thư mục hoang-dung-auto-style-learner

AI không đọc hết một lúc. Mở file theo bảng giai đoạn trong `SKILL.md`.

| Thư mục / File | Chứa | Mở khi |
|---|---|---|
| `SKILL.md` | Điểm mấu chốt + Bảng định tuyến nhiệm vụ → file cần đọc | Luôn luôn, đầu tiên |
| `rules/` | Luật cứng bóc tách, cổng chất lượng 100/100 (`R-L033`), quy tắc 3 pha & đặt tên | Đầu phiên học; trước khi nộp kết quả |
| `workflow/` | Quy trình chi tiết từng nhiệm vụ (Đo đạc, Lập Template, Học hiệu ứng, B-roll/MG, Tự học) | Khi tới đúng nhiệm vụ |
| `references/` | Sổ tay Editor Pro 8 thành phần (`editor-chuyen-nghiep-8-thanh-phan.md`), Cẩm nang Sound Design chuyên sâu (`sfx-sound-design-chuyen-sau.md`), Schema Template (`template-video.md`), Đội Agent (`doi-agent.md`) | Khi workflow trỏ tới |
| `scripts/` | Script đo đạc (`measure_video.py`), kiểm tra (`template_check.py`), chấm điểm (`template_similarity.py`) | Khi chạy công cụ đo và kiểm cổng |
| Bridge Tool (`.gemini/antigravity/scratch/hdre_antigravity_bridge/`) | MCP server, trích xuất dữ liệu, tự động tái tạo HyperFrames, preset chữ/overlay/khung/phụ đề | Khi gọi công cụ tự động |
