# Bản đồ thư mục dung-video

AI không đọc hết. Mở file theo bảng giai đoạn trong `SKILL.md`.

| Thư mục | Chứa | Mở khi |
|---|---|---|
| `SKILL.md` | Điểm mấu chốt + bảng giai đoạn → file cần đọc | luôn, đầu tiên |
| `rules/` | Luật cứng, luật từng agent, cổng chất lượng, quyết định 02/11/2026 | đầu dự án; khi giao việc; khi kiểm cổng |
| `workflow/` | Quy trình từng giai đoạn (làm gì, theo thứ tự nào, nộp gì) | khi tới đúng giai đoạn |
| `resources/` | Brief agent tiếng Anh, đường dẫn máy, nguồn dẫn chứng, bảng quyết định nhanh | khi cần tra |
| `references/` | Chi tiết kỹ thuật: màu sắc (`color-pipeline.md`, `chon-lut.md`), chữ hiệu ứng (`text-fx/01`–`06`), sound design đa tầng (`sfx-sound-design-chuyen-sau.md`, `audio-gate.md`), bản đồ, che địa chỉ, routing, preset | khi workflow trỏ tới |
| `textfx-kit/` | Script (`color_engine.py`, `vn_font_gate.py`), font, thư viện SFX, recipe | khi chạy công cụ |
