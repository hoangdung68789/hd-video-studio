# HDRE_Library – Thư mục tài nguyên dùng chung của các skill Hoàng Dũng

Đường dẫn trên máy: `~\Documents\HoangDung_AI\HDRE_Library`
(ghi trong `HDRE_Edit\project\assets_path.txt` của mỗi dự án để skill tự tìm).

Tạo ngày 17/10/2026. Mọi file là Markdown / CSV / WAV thường, mở được bằng Notepad, Excel, trình phát nhạc.
